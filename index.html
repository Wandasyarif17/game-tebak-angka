Komputer menyembunyikan satu angka. Tugasmu menebaknya — setiap tebakan dikasih petunjuk terlalu besar atau terlalu kecil, plus suhu kedekatanmu. Di bawah game-nya ada kode aslinya, jadi habis main kamu bisa lihat persis cara kerjanya.

✅ Ini file lengkapnya — tinggal paste SEKALI

Bro, file ini sudah digabung jadi satu: HTML + CSS + JavaScript ada di dalam satu file yang sama. Jadi kamu nggak perlu paste CSS dan JavaScript satu-satu lagi. Cukup salin file ini sekali, tempel ke editor, simpan sebagai index.html, terus buka — game-nya langsung jalan.

Di mana CSS dan JavaScript ditaruh? Ini rumusnya, lihat kerangkanya:

<!DOCTYPE html> <html> <head> <title>Game Tebak Angka</title> <style> ... CSS ditempel DI SINI ... </style> </head> <body> ... HTML game-nya DI SINI ... <script> ... JavaScript ditempel DI SINI ... </script> </body> </html>

Ingat aja dua baris ini: CSS di dalam <style> di bagian <head>, dan JavaScript di dalam <script> tepat sebelum </body>. Di file ini, dua-duanya sudah saya taruh di tempatnya — kamu nggak usah mindahin apa-apa.

  3. Simpan dengan nama index.html, lalu buka file itu di browser. Selesai!

Cara kerja game ini

Game sekecil ini pun dibangun dari tiga bahan yang sama seperti website mana pun:

HTML

Kerangkanya. Kotak input, tombol “Tebak”, tempat petunjuk muncul — semua ditulis pakai tag HTML.

CSS

Tampilannya. Warna hijau, sudut membulat, ukuran huruf — CSS yang mengatur game ini kelihatan seperti ini.

JavaScript

Otaknya. Yang mengacak angka rahasia, mengecek tebakanmu benar atau salah, dan menghitung percobaan.

  1. Komputer mengacak angkaSaat game mulai, JavaScript menjalankan Math.random() untuk memilih satu angka rahasia, lalu menyimpannya di variabel.
  2. Kamu menebakTombol “Tebak” memicu sebuah function yang membaca angka dari kotak input.
  3. JavaScript membandingkanPakai if / else: kalau sama persis → menang; kalau tebakanmu lebih kecil → petunjuk “terlalu kecil”; kalau lebih besar → “terlalu besar”.
  4. Skor dihitungSetiap tebakan menambah variabel percobaan sebanyak 1 (percobaan++). Makin sedikit percobaan, makin bagus skormu.

Lihat kodenya

Ini kode game di atas, disederhanakan sedikit biar gampang dibaca buat belajar per bagian. Kalau mau pakai game-nya beneran, jangan salin per tab — pakai tombol Salin Kode Lengkap di paling atas, itu yang menyalin satu file utuhnya sekali paste.

Rumus JavaScript yang dipakai

Empat baris ini yang bikin game-nya “hidup”. Sisanya cuma pengulangan pola yang sama.

Math.floor(Math.random() * 100) + 1

Mengacak angka bulat dari 1 sampai 100. Math.random() memberi angka acak 0–0,99…, dikali 100, dibulatkan ke bawah, lalu ditambah 1.

if (tebakan === rahasia) { … }

Membandingkan dua angka. Tanda === artinya “sama persis?”. Kalau benar, blok di dalam kurung kurawal yang jalan.

else if (tebakan < rahasia) { … }

Cabang kedua: kalau tebakan lebih kecil dari angka rahasia, tampilkan petunjuk “terlalu kecil”. Kalau tidak juga, jatuh ke else terakhir.

tombol.addEventListener("click", cek)

Menyuruh browser: “kalau tombol ini diklik, jalankan fungsi cek”. Inilah yang menghubungkan klik kamu ke logika game.

Tantangan buat latihan: salin kode lengkapnya pakai tombol di atas, tempel ke editor, lalu ubah angka 100-nya jadi 10 — game-nya langsung berubah jadi tebak angka 1–10. Begitulah rasanya ngoding: ubah satu angka, perilaku program ikut berubah.
